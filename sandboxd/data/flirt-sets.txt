# The FLIRT signature sets sandboxd/samplehooks.py matches a program
# against, and the only ones it loads. Hand-edited.
#
#     <os> <bits> <toolchains> <set> [<convention>]
#
# os          linux or windows (an ELF is linux, a PE windows), or *
# bits        32 or 64, or *
# toolchains  comma-separated, of c, go, rust, nim, zig -- c being any
#             program no other was recognised in (samplehooks.toolchain) --
#             or *
# set         a glob under sandboxd/data/flirt/, without the extension: a
#             `.sig` (Hex-Rays'), `.pat.gz` or `.pat` (scripts/gen-flirt-pats.py)
#             of that name is the set. `{rust}` is the Rust release that
#             built the program, from its .comment or its compiler's commit;
#             a line with it is passed over when neither says.
# convention  only, and always, on a line for Go alone: a set of Go's
#             standard library, tried when the program's own function table
#             names nothing (garble). Where what the set names takes its
#             arguments: goabi (registers), goabi0 (the stack), go (the
#             program's release decides).
#
# Order is precedence: a function start is offered to the sets in this
# order, and the first that names it names it.
#
# The sets under ida/flirt/ are Hex-Rays' signature bundle (the
# signatures-bundles-<version>.zip published beside IDA Free), unpacked by
# `make signature_sets IDA_SIGNATURES=<the zip>` (scripts/install-ida-flirt.py),
# which unpacks only what a line here names: after adding one, run it again.
# The bundle has no uClibc: a set for it is scripts/fetch-flirt-sets.py's,
# named here by its own name.
