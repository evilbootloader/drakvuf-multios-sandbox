# Go functions worth a hook, for programs written in Go (sandboxd/samplehooks.py).
#
# A Go program is one statically linked file: nothing of it is an export, and
# its calls never pass through libc or, mostly, a Windows DLL above ntdll. The
# program's own function table names every function in it; the ones listed
# here are hooked where that table says they are, in the sample's image.
#
# A line is a hook list's, with `go` where the module goes:
#
#   go,<function as Go's table spells it>,<goabi|goabi0>,log[,<Name>:<type>...]
#
# goabi   a function written in Go. Its arguments are in registers from Go
#         1.17 on amd64 and on the stack before that and on 32-bit; the
#         locator writes whichever the sample's version has.
# goabi0  a function written in assembly: on the stack in every version.
#
# Arguments are machine words in the order of the declaration, and Go's own
# types take more than one:
#   string     pointer, length        Name:buffer[NameLen],NameLen:ulong
#   []byte     pointer, length, cap   Data:buffer[DataLen],DataLen:ulong,DataCap:ulong
#   interface  type, data             CtxType:lpvoid,Ctx:lpvoid
#   a method   its receiver first
# `ulong` for Go's int and uintptr (a word), `dword` for a uint32.
# No return values: a goroutine's stack moves, see parse_entry() in DRAKVUF.
#
# Hand-written and hand-checked against the standard library's declarations.
# Leave out what runs per byte or per packet ((*File).Write, (*conn).Read).
